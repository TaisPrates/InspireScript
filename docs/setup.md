# ⚙️ Setup do Projeto

## 📋 Requisitos

- Python 3.x
- MySQL
- Git
- Navegador web

---

## 🚀 Instalação

### 1. Clonar o repositório

```bash
git clone <URL_DO_REPOSITORIO>
cd InspireScript
```

### 2. Criar ambiente virtual
```
python -m venv venv
```

### 3. Ativar ambiente virtual

Windows:
```
venv\Scripts\activate
```
Linux / Mac:
````
source venv/bin/activate
````
### 4. Instalar dependências
```
pip install -r requirements.txt
```
⚠️ O arquivo requirements.txt será atualizado conforme a evolução do projeto.

🗄️ Banco de dados
Criar o banco no MySQL
Executar os scripts disponíveis na pasta ```database/```

📌 Observação

O projeto está em desenvolvimento. Algumas etapas podem mudar conforme novas funcionalidades e tecnologias forem adicionadas.
