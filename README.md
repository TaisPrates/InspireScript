**Plataforma para organização e desenvolvimento de ideias literárias**

---

## 📖 Visão Geral

O **InspireScript** é uma aplicação web desenvolvida para auxiliar escritores na organização, estruturação e evolução de ideias criativas.

A proposta é oferecer um ambiente centralizado onde elementos fundamentais de uma narrativa possam ser organizados de forma clara e contínua ao longo do tempo.

---

## 🎯 Objetivo

Construir uma plataforma que permita:

* Centralizar o processo criativo de escrita  
* Estruturar ideias de forma organizada  
* Evoluir conceitos narrativos de forma contínua  
* Servir como base para futuras extensões inteligentes  

---

## ✨ Diferenciais

* Organização estruturada de elementos narrativos  
* Separação clara entre camadas da aplicação  
* Arquitetura pensada para crescimento  
* Projeto desenvolvido com foco em boas práticas de engenharia  

---

## 🧩 Arquitetura

A aplicação segue uma estrutura em três camadas principais:

* **Front-end:** Interface de interação com o usuário  
* **Back-end (FastAPI):** Regras de negócio e API  
* **Banco de dados (PostgreSQL):** Persistência das informações  

### Fluxo da aplicação

Usuário → Interface → API → Banco de Dados
